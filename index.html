The core idea

A shared foundation on SharePoint.A private layer that's all yours.

A brain keeps a stable base of knowledge, then refines it through lived experience. SE Brain mirrors that with a two-tier model: a universal SharePoint raw dump every SE shares, compiled into a local wiki — plus your own KB-Local notes layered on top, never overwriting shared truth, just sharpening answers for you.

Shared SharePoint foundation

The authoritative raw dump every SE shares, reached through the se-graph-wiki MCP tools. One source of truth behind every answer.

Tier 1 · Universal

Private KB-Local layer

A gitignored folder of your personal notes and deal context, folded in only when it adds value — and clearly labeled when it does.

Tier 2 · Private

One local wiki

Synthesized, cross-linked, source-cited knowledge — the single brain the SE actually talks to, and the one thing that compounds.

The toolkit

The skills the agent composes

Each skill is a single SKILL.md with trigger phrases and a step-by-step workflow. Together they research, build, query, and maintain the brain — navigating the local wiki and fetching data from the SharePoint dump, with KB-Local as the optional private layer.

01

se-query-wiki

Navigates the local wiki for the map and context, fetches the cited data from the SharePoint dump, and synthesizes a source-cited answer. Substantial answers get filed as analyses/ pages so insight compounds.

what does the wiki say · compare X and Y · analyze
02

se-wiki-generator

Reads the SharePoint dump plus KB-Local and compiles the local wiki/ — summaries, concepts, entities, comparisons, overview, index, and changelog. Updates incrementally as sources arrive.

build the wiki · ingest sources · update wiki
03

se-customer-intel

Generates sharp pre-meeting briefs — talking points, landmines, demo plan — grounded in the wiki, then enriched with account & pipeline data and your private KB-Local notes.

prep me for a meeting · customer brief · account context
04

se-open-research

Scours the web for articles, papers, and data, converts each to clean markdown with frontmatter, and saves them to the SharePoint raw dump for ingest.

research X · gather sources · find papers
05

se-work-research

Gathers internal context — Outlook, Teams, meetings, and shared docs via the WorkIQ MCP server — and saves it to the SharePoint dump with a work-- prefix.

check work emails · internal context · team discussion
06

se-lint-wiki

Runs 7 health checks — orphans, dead links, stale content, contradictions, gaps, backlinks, index drift. Auto-fixes safe issues; asks before warnings.

lint the wiki · health-check · find gaps
07

se-html-explainer

Turns dense markdown — wiki pages, raw sources, or answers — into polished, self-contained HTML explainers with real visual hierarchy. Saves to html-files/.

visualize this · make an explainer · convert to HTML
08

se-make-skill-template

A meta-skill for creating new skills. Scaffolds the folder, generates SKILL.md with proper frontmatter, and supports bundled scripts and assets — so the brain grows new capabilities on demand.

create a skill · scaffold a skill · new skill
End to end

A session, start to finish

An SE asks; the agent routes; skills run against the knowledge base; a grounded answer comes back — and the brain is left a little smarter every time.

  1. 01

    SE asks

    Onboarding, enablement, tooling, stakeholders, or account help — in plain language. No files, no paths, no wiki mechanics to learn.

    plain-language intent
  2. 02

    Agent routes

    The agent interprets the request and decides which skills and knowledge-base paths it needs to answer well.

    intent → skills
  3. 03

    Skills run

    Query, ingest, lint, or generate — local wiki first for the map, then the SharePoint dump for the data, then optional KB-Local for your private context.

    wiki → SharePoint → KB-Local
  4. 04

    Knowledge compounds

    Substantial results are filed back as analyses; backlinks and the index are updated — so every future answer starts richer.

    the compounding loop ↺
  5. 05

    Agent replies

    A grounded, source-cited answer — checklist, plan, brief, or HTML explainer — returns to the SE.

    grounded & cited

Guardrails

Six rules that keep the brain trustworthy

Grounding rules the agent follows on every answer — so the brain stays accurate, attributable, and honest about what it doesn't know.

1

Navigate the wiki, fetch from SharePoint. The local wiki gives the map and context; the real data is fetched from the SharePoint raw dump via wiki_read — never a stale local mirror.

2

KB-Local augments, never substitutes. Private notes add personal context only; if SharePoint is down, the agent stops rather than answering from local alone.

3

SharePoint wins conflicts. When a local note disagrees with shared truth, SharePoint prevails and the discrepancy is flagged to you.

4

Label where it came from. Local-sourced content is marked "From your local notes (KB-Local)" so you always know what's shared vs. personal.

5

Every claim traces to a source. No hallucinated facts; answers cite the wiki pages and SharePoint raw sources they used as clickable links.

6

Explorations compound. Substantial answers are filed back to the local wiki as analyses — the brain grows richer with every session.
