# SE Glossary

Common terms, acronyms, and abbreviations used in the SE organization.

## Sales & Engagement

| Term | Definition |
|------|-----------|
| **AE** | Account Executive — owns the commercial relationship |
| **SSP** | Solution Sales Professional — leads solution-specific deals |
| **CSA** | Cloud Solution Architect — deep technical guidance post-sale |
| **TSP** | Technical Sales Professional — pre-sales technical resource |
| **SE** | Solution Engineer — pre-sales technical advisor (your role) |
| **MCEM** | Microsoft Customer Engagement Methodology — 5-stage deal framework |
| **Technical Win** | Customer agreement that the technical solution meets their needs |
| **POC** | Proof of Concept — hands-on validation of a solution approach |
| **RFP/RFI** | Request for Proposal / Request for Information |

## Tools & Systems

| Term | Definition |
|------|-----------|
| **MSX** | Microsoft Sales Experience — CRM and opportunity management |
| **MSXi** | MSX Insights — pipeline and performance reporting |
| **RAIN** | Role and Incentive Navigator |
| **RBI** | Results-Based Incentives — compensation model |
| **MCAPS** | Microsoft Customer and Partner Solutions (the org) |
| **Seismic** | Sales enablement content platform |
| **FastTrack** | Post-win deployment support program |

## Cloud & Technical

| Term | Definition |
|------|-----------|
| **ACR** | Azure Consumed Revenue — actual Azure usage revenue |
| **CAF** | Cloud Adoption Framework |
| **WAF** | Well-Architected Framework |
| **IaC** | Infrastructure as Code |
| **AKS** | Azure Kubernetes Service |
| **RAG** | Retrieval Augmented Generation (AI pattern) |

## Organization

| Term | Definition |
|------|-----------|
| **Pod** | Team unit of 5-10 SEs covering a sector/account set |
| **Sector** | Industry vertical grouping (ITUS, DN, Manufacturing, PS) |
| **STU** | Solution Technical Unit — the SE org |
| **ATU** | Account Team Unit — the sales team covering accounts |
