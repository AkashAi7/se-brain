# SE Onboarding Platform Documentation

The platform transforms SE onboarding through an intelligent, AI-powered, personalized experience.

## Platform Capabilities

### First-Login Experience
- Personalized around the SE's role, domain, and assignment context
- Auto-resolves organizational relationships and team structure
- Generates a personalized access checklist

### Account Intelligence
- Assigned accounts shown with segment classification and active opportunity context
- Natural-language account queries
- Synthesized account context and customer profile updates
- Shared history when any SE opens a customer account
- Competitive and positioning insights (e.g., AWS entrenchment, Azure differentiation)

### Dynamic Tool Surfacing
- Tools surfaced based on SE's active context (not a static list)
- Connects onboarding, execution context, and reusable wiki artifacts
- Wiki generation for customer/opportunity context when opportunities are created in MSX

### Workflow Orchestration
- Access and environment readiness as guided platform actions
- Account deep dives and relationship mapping driven by live account context
- Shadowing, first-customer-meeting support, and manager check-ins as workflow milestones
- Certifications, labs, and skilling guidance integrated into the personalized experience

### Learning & Skill Model
- Certification roadmap milestones
- Role-aligned guidance adapting to SE's assignment and current stage
- Cloud and developer skilling themes: CI/CD, hybrid cloud, Kubernetes, GitOps, IaC
- Personalized learning path recommendations

## Platform Surfaces

| Surface | Purpose |
|---------|---------|
| MCAPS Onboarding Hub | Central onboarding dashboard |

| Account Intelligence | Live customer insights |
