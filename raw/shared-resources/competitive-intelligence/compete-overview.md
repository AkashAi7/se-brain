# Competitive Intelligence

## Quick Positioning

| Dimension | Azure Strength | Against AWS | Against GCP |
|-----------|---------------|-------------|-------------|
| AI/ML | Foundry, OpenAI exclusivity, Copilot ecosystem | More integrated AI stack, OpenAI partnership | Broader model variety, enterprise governance |
| Enterprise | M365 integration, Entra ID, hybrid (Arc) | Deeper enterprise identity story, hybrid | Office integration, compliance posture |
| Data | Fabric unified platform, OneLake | Unified lake+warehouse in Fabric | Less complex than BigQuery ecosystem |
| DevOps | GitHub + Azure DevOps, Copilot for dev | Tighter GitHub integration | Superior CI/CD with GitHub native |
| Pricing | Reservations, Savings Plans, hybrid benefit | Azure Hybrid Benefit (existing licenses) | Similar base pricing |

## Key Compete Scenarios

### GCP Displacement (e.g., Tata Steel pattern)

1. Start with AI Companion / Copilot success as wedge
2. Show Azure AI Foundry advantages over Vertex AI
3. Bridge with Fabric for data (replacing BigQuery dependency)
4. Governance and compliance as differentiators

### AWS Migration

1. Lead with cost optimization (Azure Hybrid Benefit for Windows/SQL)
2. M365 + Azure integration story
3. AI/Copilot as differentiated value
4. Express Route vs Direct Connect parity
