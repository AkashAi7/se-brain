# SE Onboarding Overview

## Purpose

This directory provides a structured **PATH** through SE onboarding content. It does not duplicate knowledge — it references into `se-roles/{role}/`, `shared-resources/`, and `sectors/{sector}/` where the actual content lives.

## Phased Journey

| Phase | Timeline | Focus |
|-------|----------|-------|
| Phase 1 — Orientation | Day 1-3 | Identity, access, people, tools, culture |
| Phase 2 — Role Fundamentals | Week 1-2 | Role charter, sales motion, MCEM, tools deep-dive |
| Phase 3 — Technical Depth | Week 2-4 | Cloud stack, certifications, hands-on labs |
| Phase 4 — Customer Readiness | Month 2 | Shadowing, co-delivery, account engagement |
| Phase 5 — Ongoing Development | Month 3+ | Independent ownership, specialization, contribution |

## Weekly Rhythm During Onboarding

- **Monday**: Onboarding Live (~5 hours of live virtual sessions)
- **Tuesday–Thursday**: Practice Engine (~3-4 hours guided practice, shadowing, study circles, buddy help, AI coaching)
- **Friday**: Community and readiness check (~1-2 hours — Experience MCAPS, reflection, scenario-based assessment)
- ~10 hours/week of protected onboarding time

## Key Systems

- MCAPS Onboarding Hub: https://aka.ms/MCAPSOnboarding_RBOHub
- MCAPS Onboarding Agent: https://aka.ms/OnboardingAgent
- SuccessFactors Learning: via MyHub / HR Web
- MCAPS Academy: https://microsoft.sharepoint.com/teams/MCAPSAcademy

## How This Directory Works

Each phase folder contains:
- `checklist.json` — tasks/milestones for that phase
- `role-track-refs.json` — pointers into `se-roles/{role}/` for role-specific content
- Phase-specific guidance markdown files

The content itself lives in canonical locations (`se-roles/`, `shared-resources/`, `sectors/`). Onboarding only links to it.
