# MCEM — Microsoft Customer Engagement Methodology

## The 5 Stages

| Stage | SE Focus | Deliverables |
|-------|----------|-------------|
| **1. Discover** | Understand customer pain, map stakeholders | Discovery notes, stakeholder map |
| **2. Qualify** | Validate technical fit, identify blockers | Technical qualification, compete landscape |
| **3. Solution** | Design and demo the solution | Architecture, demo, technical win criteria |
| **4. Prove** | POC/pilot execution | POC results, success metrics |
| **5. Close** | Remove final blockers, support procurement | Reference architecture, deployment plan |

## SE Responsibilities by Stage

### Discover
- Join discovery calls (listen, ask technical questions)
- Document current architecture and pain points
- Identify decision makers and technical influencers

### Qualify
- Assess technical feasibility
- Map competitive landscape (what's in place, what's being evaluated)
- Define success criteria with the customer

### Solution
- Design reference architecture
- Deliver demos tailored to customer scenarios
- Secure the Technical Win (customer agrees the solution works)

### Prove
- Execute POC with clear success metrics
- Handle technical objections
- Document results and lessons learned

### Close
- Support final technical questions
- Provide deployment planning guidance
- Hand off to CSA/FastTrack for post-win
