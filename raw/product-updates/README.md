# Product Updates

Track product changes, feature releases, and their impact on SE workflows and customer conversations.

## Directory Structure

```
product-updates/
├── by-product/           # Updates organized by Azure/M365/Security/etc.
├── filtered-views/       # Role-specific and sector-specific views
├── announcements/        # Official announcements and timelines
└── impact-analysis/      # What changes mean for SEs and customers
```

## How To Use

1. **by-product/**: File new updates under the relevant product folder (e.g., `by-product/azure-ai/`, `by-product/m365/`)
2. **filtered-views/**: Auto-generated views filtered by role track or sector relevance
3. **announcements/**: GA dates, preview availability, deprecations
4. **impact-analysis/**: How a product change affects demos, pitches, or customer recommendations

## Conventions

- Each update file should include: date, product, change summary, SE impact, and customer talking points
- Tag with relevant role tracks and sectors for filtered view generation
