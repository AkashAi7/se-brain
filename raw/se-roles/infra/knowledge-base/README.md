# Infrastructure Solutions Engineer — Knowledge Base

## Role Charter

Infrastructure SEs focus on Azure compute, networking, storage, and migration. They help customers modernize infrastructure, optimize costs, and adopt cloud-native patterns.

## Core Domains

- **Azure Compute** — VMs, VMSS, AKS, Container Apps, App Service
- **Azure Networking** — VNets, ExpressRoute, Front Door, Firewall, Private Link
- **Azure Storage** — Blob, Files, Managed Disks, NetApp Files
- **Migration** — Azure Migrate, ASR, database migration
- **Hybrid** — Azure Arc, Azure Stack HCI, hybrid connectivity

## Key Scenarios

| Scenario | Pattern | Tools |
|----------|---------|-------|
| DC migration | Assess → migrate → optimize | Azure Migrate, ASR |
| Modernize to containers | Lift-and-shift → containerize → AKS | AKS, Container Apps |
| Hybrid connectivity | ExpressRoute + VPN + Arc | Azure Arc, networking |
| Cost optimization | Right-sizing + reservations + advisor | Cost Management, Advisor |
