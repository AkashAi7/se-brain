# Software Solutions Engineer — Knowledge Base

## Role Charter

Software SEs focus on application development, DevOps, and app modernization on Azure. They help customers build cloud-native applications and modernize legacy systems.

## Core Domains

- **App Development** — App Service, Container Apps, Functions, Logic Apps
- **DevOps** — Azure DevOps, GitHub Actions, CI/CD pipelines
- **Modernization** — Legacy app migration, microservices, API management
- **Integration** — API Management, Service Bus, Event Grid, Logic Apps
- **Developer Experience** — VS Code, GitHub Copilot, Dev Box, Deployment Environments
