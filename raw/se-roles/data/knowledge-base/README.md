# Data Solutions Engineer — Knowledge Base

## Role Charter

Data SEs focus on Azure data platforms, analytics, and data-driven AI. They guide customers through data modernization, real-time analytics, and governance.

## Core Domains

- **Azure SQL & Databases** — SQL DB, Cosmos DB, PostgreSQL, MySQL
- **Analytics** — Synapse, Fabric, Data Explorer, Data Factory
- **Data Governance** — Purview, data catalogs, lineage, compliance
- **Real-time** — Event Hubs, Stream Analytics, Fabric Real-Time Intelligence
- **Data AI** — Azure Machine Learning, Databricks, AI workloads on data
