# AI Solutions Engineer — Knowledge Base

## Role Charter

AI Solutions Engineers focus on Azure AI, Copilot, and intelligent application solutions. They guide customers through AI adoption — from proof of concept to production deployment.

## Core Domains

- **Azure AI Foundry** — Model catalog, fine-tuning, AI agents, prompt engineering
- **Microsoft Copilot** — M365 Copilot, Copilot Studio, custom copilots
- **Azure OpenAI Service** — GPT models, embeddings, RAG patterns
- **Azure AI Services** — Vision, Speech, Language, Document Intelligence
- **Responsible AI** — Fairness, transparency, safety, governance

## Key Scenarios

| Scenario | Pattern | Tools |
|----------|---------|-------|
| Enterprise search & RAG | Knowledge mining + vector search + LLM | Azure AI Search, Azure OpenAI |
| Custom copilot | Copilot Studio + plugins + grounding | Copilot Studio, Dataverse |
| Document processing | OCR + classification + extraction | Document Intelligence, Logic Apps |
| AI agent workflows | Multi-agent orchestration | Azure AI Foundry, Semantic Kernel |
