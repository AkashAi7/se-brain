# Analysis: Seamless Onboarding Playbook

## Question

What does an end-to-end, friction-free SE onboarding look like from Day 1 to Day 30+?

## Short Answer

A seamless ramp threads three things continuously: **access provisioned early**, **relationships built deliberately**, and **skills layered in stages** — with the [Onboarding Agent](https://aka.ms/OnboardingAgent) providing weekly stage-aware nudges so nothing is missed.

## What Makes It Seamless

1. **Front-load access.** Submit every tool request Day 1 (MSX, MSXi, RAIN, MSX Earnings, Learn) — provisioning latency is the top blocker.
2. **People as accelerators.** A named buddy plus early AE/CSAM/GBB intros unblock context and accounts faster than any document.
3. **Layered skilling.** Don't front-load everything: fundamentals (Wk2) → methodology (Wk3-4) → live deals. Use Microsoft Learn + Agent J.ai for pitch practice.
4. **Weekly guidance loop.** The Onboarding Agent gives stage-specific actions; the SE checks in instead of guessing what's next.
5. **Tool clarity early.** Resolve the MSX Earnings (comp) vs MSXi (pipeline) distinction up front to avoid recurring confusion.

## Common Friction Points (and Fixes)

| Friction | Fix |
|----------|-----|
| Access lag | Request Day 1; escalate via manager/buddy |
| Tool confusion | Learn RAIN first; clarify Earnings vs MSXi |
| Skilling overload | Stage it; certifications over weeks, not days |
| Account ambiguity | Early AE/CSAM deep-dive + pod map review |
