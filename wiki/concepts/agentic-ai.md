# Agentic AI

## Definition

Agentic AI refers to autonomous AI systems that can perceive, reason, plan, and act to accomplish complex tasks with minimal human intervention. In the context of current engagements, this manifests as **multi-agent systems** that operate on enterprise data to perform tasks like knowledge graph construction, pipeline diagnostics, and workflow automation.

## Key Points

- **Core differentiating theme** across the engagement portfolio — appears in both IndiGo (knowledge graphs) and TCS (DevOps agents). (from [overview source](../../raw/work--projects-customers-overview-3months.md))
- IndiGo engagement demonstrates full-stack agentic implementation: graph builder agents, unification agents, LLM + cosine similarity pipelines. (from [overview source](../../raw/work--projects-customers-overview-3months.md))
- TCS engagement applies agentic patterns to DevOps: pipeline diagnostics, failure analysis, automated remediation loops. (from [overview source](../../raw/work--projects-customers-overview-3months.md))
- Agent orchestration patterns and MCP-based integration are shared architectural themes. (from [overview source](../../raw/work--projects-customers-overview-3months.md))

## Technical Patterns

- **Knowledge graph agents** — build and unify enterprise graphs using LLM + cosine similarity
- **Pipeline agents** — diagnose failures, detect root causes, auto-remediate
- **MCP-based federation** — connect agents to diverse data sources
- **Script → production-ready agent conversion** — engineering discipline applied to prototypes
