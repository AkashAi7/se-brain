# Onboarding Tooling and Resources

## Definition

The set of tools, portals, and learning surfaces a new SE must set up and learn to navigate, organized into **four practical layers**: role understanding, deal methodology, execution systems, and ongoing skilling (from [SE Tools Full Reference](../sources/se-tools-full-reference.md)).

## Key Points

- **Day 1 critical tools:** MSX, MCEM Portal, RAIN, Onboarding Agent (from [Day 1 Starter Guide](../sources/se-day-1-complete-starter-guide.md)).
- **Recommended Week 1 sequence:** RAIN → MCEM Portal → MSX → Onboarding Agent — orientation systems first, then execution, then deeper learning (from [SE Tools Full Reference](../sources/se-tools-full-reference.md)).
- **Overlapping-but-distinct tools:** **MSXi** = business/pipeline reporting; **MSX Earnings** = source of truth for quota attainment, earnings, payout; **RAIN** = role and incentive navigation.
- **Layered model:** role understanding (RAIN), deal methodology (MCEM Portal), execution systems (MSX, MSXi), ongoing skilling (Microsoft Learn, MCAPS Academy, Agent J.ai).
