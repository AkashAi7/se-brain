# Onboarding Tooling And Resources

## Definition

This page organizes the core systems and reference links a new SE needs across onboarding, execution, deal methodology, incentives, reporting, learning, coaching, and support.

## Category Model

| Category | Purpose |
|----------|---------|
| Onboarding | Get access, environment readiness, and subscriptions |
| Knowledge Base | Find the authoritative onboarding program content and its guided navigation surface |
| Execution | Work in account and opportunity systems |
| Methodology | Understand how deals flow and how account planning is expected to work |
| Incentives | Understand role mechanics, quota logic, and compensation views |
| Reporting | Review performance, dashboards, and pipeline reporting |
| Learning / Enablement | Build role knowledge and skill depth |
| Coaching | Practice messaging and improve readiness |
| Support | Find technical reference and escalation paths |
| Public References | Use public architecture, adoption, and roadmap material to deepen context |
| Certifications | Track foundational and advanced credentials aligned with the ramp |

## Week 1 tool sequence

| Sequence | Tool | Why it comes first |
|----------|------|--------------------|
| 1 | RAIN | Clarifies role expectations, plan details, and incentive context |
| 2 | MCEM Portal | Explains the deal flow and orchestration model |
| 3 | MSX | Gives the first practical view into opportunities and execution surfaces |
| 4 | Onboarding Agent | Keeps weekly ramp tasks and learning on track |

## Insight And Knowledge-Base Surfaces

- MCAPS Onboarding Hub is the authoritative source for onboarding schedules, resources, and program content.
- Onboarding Agent is the guided navigation layer for that knowledge base in Teams and Microsoft 365.
- MSXi is the business-performance and readiness dashboard, not the source of onboarding instructions.
- Power BI complements MSXi for territory and pipeline reporting.
- Mint is separate again and should be used for quota and earnings tracking rather than business-performance review.

## High-value distinctions

- MSXi is the business-performance and pipeline-reporting surface.
- MCAPS Onboarding Hub and the Onboarding Agent answer program and process questions, while MSXi answers business-performance questions.
- MSX Earnings is the source of truth for quota attainment, earnings, and payouts.
- RAIN explains role and incentive structure, while MCEM Portal explains how the selling motion is expected to run.
- Seismic is the fastest path to battlecards, decks, and solution play material once a seller knows what motion or product to study.

## Practical Onboarding Use

- Start with MCAPS Onboarding Hub and the Onboarding Agent so the SE has the right authoritative knowledge base before chasing links manually.
- Use RAIN and MCEM Portal first so the role model and the deal model are clear before deeper system use.
- Use MSX, MSXi, and Power BI once the SE needs practical visibility into opportunities, pipeline, and business performance.
- Use the incentives stack separately from the reporting stack so compensation questions do not get mixed with pipeline reporting.
- Use Seismic, Microsoft Learn, MCAPS Academy, job shadowing, Study Circles, and the coaching tools as the ongoing readiness layer throughout the first month.
