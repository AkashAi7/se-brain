# Onboarding Platform Capabilities

## Definition

The onboarding platform capabilities are the set of personalized, AI-assisted, and workflow-driven features that help a new SE move from setup to productive execution.

## Key Capabilities Visible In Current Sources

| Capability | What it does |
|-----------|---------------|
| Personalized dashboard | Tailors onboarding to role, domain, and assignment context |
| Access checklist | Tracks environment and system readiness |
| Org and pod resolution | Shows manager, peers, and supporting stakeholders |
| Account intelligence | Surfaces customer context and live insights |
| Tool recommendations | Brings the right systems into view based on active context |
| Learning guidance | Surfaces certifications, labs, and learning paths |
| Wiki integration | Connects live workflow with reusable documentation |

## Why It Matters

- It turns onboarding from a static checklist into an adaptive working surface.
- It reduces the time between first login and meaningful customer execution.
- It makes wiki content operational instead of archival.
