## Core Technical Themes

Five themes cut across all engagements:

1. **[Agentic AI](concepts/agentic-ai.md)** — The #1 differentiator. Knowledge graph agents (IndiGo), pipeline auto-fix agents (TCS), MCP-based orchestration.

2. **[Agentic DevOps](concepts/agentic-devops.md)** — AI-native pipelines. Jenkins→GH Actions migration, diagnostics agents, automated remediation. Positions GitHub as the AI-native SDLC platform.

3. **[Copilot Governance & Billing](concepts/copilot-governance-billing.md)** — Enterprise cost architecture. UBB, BYOL, cost centers, AI credits. A rare SE differentiator (few go deep here).

4. **[Enterprise Adoption](concepts/enterprise-adoption.md)** — Scale enablement patterns. Persona-based programs, champion models, 500-person events, metrics/ROI tracking.

5. **[MCP Integration](concepts/mcp-integration.md)** — The architectural glue. Connects agents to enterprise data (Snowflake, Blue Prism, internal systems). Recurring pattern across IndiGo and TCS.
