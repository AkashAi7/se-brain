# Genpact

## Description

Genpact is an **adoption + licensing + governance-heavy engagement** — focused on Copilot rollout, enterprise enablement, and billing architecture. Represents the trusted advisor / governance expert role.

## Engagement Profile

| Dimension | Detail |
|-----------|--------|
| **Engagement Type** | Copilot rollout + enterprise enablement |
| **Depth** | Medium-High (frequent meetings, tactical + strategic) |
| **Pattern** | Regular cadences, multi-session programs |
| **Role Played** | Trusted advisor on adoption + governance |
| **Duration** | Ongoing |

## Key Workstreams

### 1. Copilot Adoption Strategy
- Expanding beyond devs → QA, DevOps, BAs
- Structuring multi-session adoption programs
- Persona-based enablement

### 2. ADO + GitHub Integration
- Advising on hybrid setups (ADO boards + GitHub repos)
- Copilot CLI usage in pipelines

### 3. BYOL + Licensing Models
- Driving Bring Your Own License discussions
- Handling cost center + billing architecture questions

### 4. Metrics + Governance
- Enabling usage dashboards
- Productivity tracking

## Significance

This engagement demonstrates **enterprise governance expertise** — few SEs go deep on licensing models, cost allocation, and platform integration strategy. Differentiating capability.
