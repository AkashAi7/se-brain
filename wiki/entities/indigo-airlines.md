# IndiGo Airlines

## Description

IndiGo Airlines is the **flagship customer engagement** — a strategic AI and Agentic transformation program with deep technical involvement. This is the deepest hands-on engineering engagement in the current portfolio.

## Engagement Profile

| Dimension | Detail |
|-----------|--------|
| **Engagement Type** | Strategic AI + Agentic transformation |
| **Depth** | Very High (weekly cadences + hands-on builds) |
| **Pattern** | Weekly cadences + deep technical workshops + prototyping |
| **Role Played** | Hands-on architect + builder |
| **Duration** | Ongoing (multi-month) |

## Key Workstreams

### 1. Agentic AI Architecture & Knowledge Graph Platform
- Building **knowledge graph agents** using enterprise data sources (CLMS, Crew Portal, PEP)
- Designing graph builder + unification agents with LLM + cosine similarity pipelines
- Working on **federated knowledge graph + MCP-based architecture**

### 2. Hands-on Engineering & Prototyping
- Converting scripts → production-ready agents (graph unification agent)
- Implementing graph updates, logging improvements, deployment patterns
- Real code output, not just advisory

### 3. Business + Architecture Alignment
- Mapping IFS workflows (IJP, PEP) into AI-driven flows
- Driving agentic touchpoints in business processes

### 4. Program Maturity
- Platform + environments set up
- MCP + Snowflake integration in progress
- Weekly governance via DATA & AI syncs

## Technical Stack

- Knowledge graph agents
- LLM + cosine similarity pipelines
- [MCP (Model Context Protocol)](../concepts/mcp-integration.md)
- Snowflake integration
- Federated graph architecture

## Significance

This engagement demonstrates the **full-stack architect + builder** capability — not just advisory but actual production engineering. It is the strongest evidence of deep technical differentiation.
